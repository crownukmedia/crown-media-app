# Crown Media App

Android app project for the Crown Media mobile and TV experience.

## Tech stack

- Kotlin
- Jetpack Compose
- Android Gradle Plugin 8.5.2
- Media3 / ExoPlayer

## Modules

- `app`: main Android application module

## Getting started

1. Install Android Studio Hedgehog or newer, or use JDK 17 with the Android SDK.
2. Create a local `local.properties` file that points to your Android SDK.
3. Run `./gradlew testDebugUnitTest` to verify the project.

## Notes

- Local SDK paths and build artifacts are ignored by Git.
- The project currently targets Android SDK 34.
